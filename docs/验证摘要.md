## 修复与证据边界

真实调试修复了 FDTD 不可用的 name 属性、监视波长偏移、网格过渡引入的参考反射、弃用监视器/背景属性、Windows PID 复用误判，以及 RCWA index 层区间数据的 Python 传输问题。失败记录均留在原运行电脑。

RCWA 原有 Fresnel/镜像/平移控制不足以识别半周期绝对原点歧义。新增两档网格、两档弱折射率的解析 Born 控制，独立支持固定换算 `exp[-i*2π*m*(-P/2+dx/2)/P]`，未用 FDTD 目标拟合相位。原生文件不改写；只有绑定并重算十份真实证据的 schema 2 证书才能导出绝对 x=0 系数。

参与验收的 FDTD 数学源码指纹为 `4775e01f7e72e751`，RCWA 为 `f46c6ba466960bc5`。精度和适用范围见 [RCWA 后端说明](RCWA_后端与验收.md)；二维、恒定实折射率、正入射和矩形网格限制仍适用，透射尚未作跨后端复幅值验证。
