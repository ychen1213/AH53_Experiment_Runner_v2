# 完整 LSF 模式与本机最小验收

项目主入口为 `LSF_JSON_GUI.cmd`。原 LSF 负责建模、材料、参考仿真、偏振切换、所有 `run`、Jones 提取和原生导出。Python 负责选择输入、生成案例副本、调度、保存最终工程及核对文件。原 AH53 `schema_version=2.0` 几何生成器保留为可选模板。

## 日常操作

1. 重新打开 `LSF_JSON_GUI.cmd`，旧窗口不会自动载入升级后的代码。
2. 导入已经在当前 Lumerical 版本中可运行的完整 LSF。
3. 在参数列表选择 `h_nm`、`CD_nm` 或 `film_t_nm(1)` 等输入，点击“设为扫描参数”。数组下标从 1 开始。
4. 填写显式值，或者起点、终点和步长/点数。数值单位完全沿用 LSF。
5. 如需启用膜，选择 `film_count`，填 `1`，点击“设置固定值”。固定参数不能同时作为扫描参数。
6. 选择输出目录。高级设置中核对 API 目录、超时、依赖文件以及必须产生的原生输出。
7. 点击“规划并保存”检查案例，再点击“启动 / 续跑队列”。也可以直接启动，程序会先自动保存任务记录。无需手写 JSON。
8. 打开输出目录的 `report.html`。失败后查看对应 `worker.log`；“重试失败”只重试已有失败或不完整案例。普通续跑跳过校验有效的 DONE。

原始 LSF 不被改写。每个案例保存 `script.lsf`、`parameters.json`、`case.json`、`model.fsp`、原生结果、`worker.log` 和状态/完整性记录。旧尝试保存在 `attempts/`。停止操作针对本窗口队列拥有的进程。

## 参数区的边界

默认识别脚本顶部连续的数值标量或一维数值数组默认值。默认赋值后、首个派生表达式或执行语句前，插入独立的 `AH53_SWEEP_OVERRIDES_BEGIN/END` 覆盖块。支持显式 `AH53_PARAMETERS_BEGIN/END` 注释标记，但标记不能绕过位置和作用域检查。

重复赋值、循环/函数局部变量、派生表达式和矩阵不会被当作可改输入。覆盖点后出现 `clear`、`eval`、`feval`、`load`、`matlabload` 等可能破坏输入追踪的命令时拒绝暴露；需要先整理源脚本。程序不会猜测动态代码的影响，不做全局数字替换。

依赖文件在高级设置中显式添加，保留相对于 LSF 所在目录的子目录结构，复制到各案例并记录哈希。当前要求这些依赖位于 LSF 所在目录及其子目录；不支持把 `../` 路径自动映射进案例。脚本中的绝对路径和目录切换原样保留，输出到案例外的文件不会自动纳入完整性检查。需要隔离的导出应在原 LSF 中使用相对于案例的路径。

## 三点比较方法与范围

使用 `film_count=1`、原 `film_mode(1)=1` 的阶梯共形包覆，扫描 `film_t_nm(1)=0,100,200` nm。0 nm 为无膜；本轮没有使用平坦化填沟模式。原脚本实际设置为二维 XY，波长 643 nm。

参考组在兼容源副本中直接修改 `film_count` 默认值和 `film_t_nm` 第一个默认元素，完全不调用转换器。自动组保留默认值，由转换器插入覆盖块后经真实执行队列运行。两组均由本机 lumapi 执行完整原生 LSF，每个点由 LSF 自己执行空气 s/p 与结构 s/p 四次仿真。这里的“手改参考”指独立修改默认值的脚本副本，不声称进行过人工 GUI 点击运行。

比较工具 `tools/verify_lsf_ah53.py` 独立于执行队列：打开双方实际保存的 `model.fsp` 读取几何和材料；用 Lumerical `matlabload` 读取双方原生 MAT 文件，不重新求解，不用 Python 重算 Jones。

当前脚本的原生输出契约是 `AH53_XY_FDTD_2023R2_1_Jones.mat`，含：

`Nall, theta_deg, rss, rsp, rps, rpp, rJones, eta_s, eta_p, lam_selected, y_ref, Rs_mon, Rp_mon, sign_in`。

`rJones` 数组形状为 `[49,2,2]`。相位、基底、监视器和阶次定义沿用此源脚本，不能直接套给任意 LSF。

预定比较门限：坐标绝对误差 `1e-15 m`，材料折射率绝对误差 `1e-12`；一般原生数值数组 `atol=1e-7, rtol=1e-6`；波长和参考平面绝对误差 `1e-15 m`，阶次和入射符号要求完全一致。每份工程和结果独立核对大小及 SHA-256，不要求包含时间信息的二进制文件逐字节相同。

最终三点结果及代码指纹见本机 `local_validation/lsf_minimum_acceptance/comparison.json`；批处理原始现场在 `output_lsf_minimum_acceptance/`，手改参考现场在 `local_validation/lsf_minimum_acceptance/manual_v252/`。这些目录及材料库默认不上传公开仓库。

## 已验证与未验证

本轮验证上述三点的执行等价性、实际几何/材料和原生复数结果一致性。相关离线回归覆盖参数覆盖位置、动态赋值拒绝、缺失结果、文件篡改、失败隔离、续跑及归档。真实 Tk 控件也完成了选参数、固定值和三点规划操作。

通用报告的 DONE 只表示脚本执行完毕、工程与声明的输出通过完整性校验。没有执行 `run` 的纯建模脚本也可以完成。

本轮没有验证任意三维模型、2023 R2.1、真实外部 MDF 在此 LSF 中的使用，或原脚本本身的网格收敛和 Jones 物理定义正确性。其他脚本的结果分析需要另行约定输出字段，不默认共享监视器和相位定义。
