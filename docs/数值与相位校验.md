# 复Jones矩阵校准与验收说明

1. 物理坐标：Lumerical 2D X-Y，X为母周期，Y为高度，Z为理想无限长条纹；正入射沿-Y。
2. 偏振：s=Ez；p=(Ex,Ey)，反射出射p方向取(cosθ,-sinθ,0)；入射p默认+X。Jones行是[s_out,p_out]，列是[s_in,p_in]。
3. 参考归一化：在空空气参考仿真中测量入射复场，监视器INC1、INC2推定传播相位符号并外推到共同的 y_ref。R monitor记录复场；扣除相同偏振的空气参考R场；按母周期做 x 方向傅里叶积分；将第m级向上传播到 y_ref，除以入射复场。
4. 定义输出 `r_E`: 复数电场幅值比，给第m级出射 Jones 2x2；在本例空气到空气、正入射、无磁性材料条件下：`eta_m,beta = cos(theta_m)*sum_alpha |rE_m,alpha,beta|^2`。`r_power = sqrt(cos(theta))*r_E`。
5. **物理规范未封口处**：用 Python FDTD复场导出的正负号对Lumerical 2023 R2.1的实际取场相位约定尚未真实校验，特别是 p 输入/输出基矢与原生RCWA结果的符号关系。故输出metadata中明确写 `NOT CALIBRATED AGAINST FRESNEL`，严禁仅凭“画出了复数曲线”就声称已得到真实仪器S矩阵。
6. **必须跑的最小电磁基准**：
   - 无结构、无反射时（空气），R接近0；
   - 空气 / 无损n=1.5平面界面，比较 s/p完整复Fresnel系数与功率（正入射R=0.04）；
   - 完整AH53对称时各阶 ±m 功率一致；
   - 光栅整体移位 +100 nm，相对相位变化取绝对值：母周期16μm，±1对为4.5°、±5对为22.5°；需记录带符号约定；
   - 网格和监视器位置收敛；
   - FDTD/RCWA相同几何条件下采用统一相位参考面再比较复Jones系数。
7. 本版**二维且各向同性**，交叉项 `rsp=rps=0` 来自TE/TM解耦，并非真实3D的拟合零或未算全矩阵。
8. 当前 materials使用constant real n；需要真实Si等的 n+ik(λ) 时，不能直接将输入n当作真实材料。完整材料色散拟合未实现。
9. 无相位展开参考时，`angle`在[-π,π]内；程序的扫描图作简单unwrap，若振幅接近0会标记NaN并分段展开。零振幅时相位不可识别。
10. FDTD上方监视器、光源与几何边界的位置固定；膜增厚超出安全余量会报错，不应自动移动监视器来消除问题。
11. 位置扫描：刚性全光栅平移后各级复系数应按移位定理改变；此版本为控制变量实验而重跑，未来SMASH理想扫描不应每个位置点重跑FDTD。
12. 本机修订将所有监视器设为显式 `f=c/λ` 的单频采样，并逐阶段核查实际频率；源脉冲覆盖目标波长±100 nm。原版1 nm窄带源未用于最终验收。宽带脉冲与单频域采样并不矛盾；改变波长时仍需检查时域衰减。
13. 本机实测为 2025 R2（用户授权），不是 2023 R2.1。正入射、同向 p 基下，空气/n=1.5 的界面处 `rss=rpp=-0.2`；固定参考面处为 `(-0.2)*exp(-2i*sign_in*k0*y_ref)`。本机测得 sign_in=-1，代码拒绝未验证的相反符号。
14. Fourier 投影为 `∫E(x)exp(-i2πmx/P)dx/P`；刚性+100 nm位移的单阶变化为 `-2πm dx/P`，±阶对变化为 `-4πm dx/P`，即 -4.5°/-22.5°。不通过取绝对值掩盖符号错误。
15. `total_reflected` 是原始 R 监视器归一化通量；`eta` 从扣除空气参考后的复场导出。二者的背景定义不同，因此必须先验证空气参考残余反射功率≤1e-6，再验证功率绝对误差≤0.01、相对误差≤5%（反射率分母下限1e-3）。若背景泄漏大，不可只缩放系数以贴合功率。
16. PML 层数显式设置（本机修订默认16层 standard），每阶段保存真实网格和 E/H 原始监视器数据。FDTD区域的指定span为内部区域，PML向外添加；原始T监视器经实测及官方定义核查不在PML中。改变PML、网格等求解源码后必须重跑相应基准，旧现场保留。
17. 最小验收与门限见 `configs/physics_validation.json`、`tools/validate_physics.py`；缺失、旧指纹、不完整、非有限数据均拒绝。单次最小基准通过也不等同任意材料、网格、斜入射、RCWA或仪器的普遍校准。
